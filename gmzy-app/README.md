# 光明中医文库·学习诊断系统（UniApp Vue3）

> **工程结构**：HBuilderX 标准 uni-app Vue3 项目——根目录同层含 `App.vue` / `main.js` / `index.html`（H5 的 vite 入口，引用 `/main.js`）/ `pages.json` / `manifest.json` / `uni.scss`，manifest 带 `vueVersion: "3"`。HBuilderX 直接导入本目录即可运行到浏览器或云打包；命令行构建时把本目录整体作为脚手架的 `src/`。启动页 = `pages/index/index`（pages.json 首项）。

基于 **HBuilderX + UniApp（Vue3 语法）** 开发的跨平台离线中医学习 App，
收录光明中医函授教材 **26 部**全文精排内容（约 1300 万字、900+ 插图），
在完整文库之上内置**记忆卡、复习思考题、中医辨证辅助**三大学习系统，
全部数据打包在应用内，完全离线可用。

## 功能

- **书架**：封面网格、分类筛选（入门 / 经典方药 / 临床 / 针灸）、书籍简介卡
- **阅读器**：
  - 三种主题：宣纸 / 护眼绿 / 夜读；宋体 / 黑体切换；字号、行距调节
  - 目录抽屉（完整章节树，定位跳转）、进度条章节滑杆
  - 段内加粗标注、宽表格横向滚动、图片点击放大
  - 自动保存阅读进度，书签随记随取，点击空白处唤出/隐藏工具栏
  - **划线批注**：长按段落 → 三色高亮 / 写批注；「我的」页聚合成笔记清单，可回跳原文、一键导出
- **学习（tab）**：
  - **记忆卡 1795 张**：方剂卡（106 方）、中药卡（212 味）、穴位卡（394 穴）、
    口诀卡（398 诀）、医案卡（212 案）、病证卡（473 病证），全部由教材自动提取；
    翻面释读，左右滑动切换
  - **反向卡**：药/方/穴/病证四包支持「反向」模式——看功效主治回想名称，记忆提取训练
  - **综合模考**：17 卷题库随机抽 30 题、倒计时 25 分钟交卷判分；成绩曲线在「详表」展示，
    错题列单、可回教材原文，作答并入日常进度
  - **朗读（H5）**：单卡朗读、口诀卡 20 张连读（自动翻页），Web Speech 离线合成
  - **SM-2 间隔重复**：「已掌握 / 模糊 / 不认识」按记忆曲线排期（30 分钟 / 次日 / 逐次拉长），
    学习中心展示「今日待复习」到期队列，支持乱序与待巩固筛选
  - **复习思考题 1974 题**：来自 17 本教材各章后的思考题，真实章名分组，
    自问自答标记，「还没记住」自动进入待巩固队列，可按书重置进度
  - **原文联动**：每张卡片、每道题都带教材锚点，一键跳转阅读器对应原文段落
  - 学习总览：连续学习天数 streak、今日已学/待复习、近 7 日学习量柱状图
- **辨证（tab）**：依据教材证型规律编写的辅助推理系统
  - 按 13 组 103 项勾选症状、舌脉与妇科/出血表现 → 在 45 个常见证型中给出加权吻合度排序（Top 4）
  - **反证扣分机制**：勾选"汗出/舌淡白/苔腻"等与证型相左的表现自动降低该证排位（风寒必无汗、实热不舌淡…）
  - **红旗提示**：勾选神昏/惊风/高热/出血等急重症征象时，页面常驻就医警示
  - **症状搜索**：103 项即输即筛，不用逐组翻找；舌象/脉象长按弹出标准图谱对照
  - **问诊引导**：按主诉分步追问（发热/咳嗽/脘腹/二便/经带/小儿/情志/腰膝浮肿 8 条轨道、48 问），
    逐层收集线索后自动辨证；发热轨按"只热不寒/寒热往来"分流里热与少阳分支，
    妇科与小儿轨按首答分流 经/周期/带/产后 与 食积/疳积/惊风/遗尿 专问；
    支持跳问、回退撤销、随时"直接辨证"，与手动勾选完全联动
  - **医案辨证考**：44 道"看案选证型"题（名家医案案要 + 教材证候描述），随机抽 10 题判分计累计成绩；
    连错 2 次入错题包，点"错 N"专攻错题，连对 3 次自动释放
  - 相近证型鉴别 20 对：前两名分差 <15% 时自动展示教材鉴别要点（风寒/风热、脾气虚/脾阳虚之别）
  - 覆盖六经八纲、卫气营血（卫/营/血分）、脏腑、气血津液、妇科（痛经/带下）、儿科（食积）
  - 每个证型附：命中症状、病机、治法、代表方（含出处）、**随证加减**、参考穴位、教材出处
  - **医案考解析**：答后显示正解证型的病机与治法，知其然亦知其所以然
  - **急重双端警示**：勾选端红旗横幅 + 结果首位为急惊风/血分险证时再加就医警示；
    Top2 均逾六成时提示「两证相兼」
  - **历史恢复**：最近辨证一键「恢复重练」，装载当次勾选重新辨证
  - **舌脉图解**：28 舌 20 脉 SVG 风格示意图——舌色/舌形/舌态/苔色/苔质五分（兼苔细分：白润/白干/黄厚/黄腻/黄燥/灰黑、腐苔/剥苔/镜面），浮沉迟数洪微散虚弱实波形 + 结代促停搏节律 + 寸关尺指位
  - **望诊图卡**：16 卡——五色面色（青赤黄白黑）、得神/失神/假神、目赤/白睛发黄、唇白/唇红干裂/唇紫、小儿指纹风关气关命关、舌面五脏分部图
  - **闻诊知识卡**：12 卡——听声音 9（语声亢微/喘哮/短气少气/干咳辨/咳重浊辨/新嗄旧喑/呃逆嗳气/太息）+ 嗅气味 3（口气/痰涕/二便）
  - **问诊·十问歌拆解**：原文歌诀卡 + 一问寒热至十问病因 10 卡 + 兼问（服药机变/妇人经带/儿科）3 卡
  - **舌脉↔辨证引擎反向桥接**：34 条舌脉图卡点击直接勾选/取消对应症状（多候选弹候选单），图上实时显核对态
  - **切诊按诊卡**：10 卡——虚里/脘腹/腹痛喜拒/胁下积块（按胸腹）+ 肌肤润燥/水肿凹陷辨/尺肤/手足温凉（按肌肤手足）+ 俞穴压痛/小儿囟门（按俞穴），WenSvg 三种按诊手势图标
  - **脉象点波动画**：图谱脉波走「心电图式」行走亮点，动画周期与脉率同步（迟 2.2s→裁 0.55s），结代促波中自带停搏，芤革带中空影波；prefers-reduced-motion 自动降级
  - **图考坐堂**：舌/脉/望 63 图随机抽考（每次 8 题、同类干扰选项），答后显图谱要点与出处；渲染歧义词条（如「白润苔」与「淡红·薄白苔」同图）自动剔除
  - **图谱账本**：自动统计每条术语的查原文次数与图考对错——弱项标红旗，可持续积累「我的薄弱诊法」
  - **长按原文卡**：长按下条目弹出底部原文卡（大图 + 释义 + 出处，不跳搜索），可继续浏览图谱或一键去检索原文
  - **考举 · 大试三科**：医案辨证 / 图考坐堂 / 综合模考统一入闱页——段位卡（元气值/九阶令/距下一阶进度条）+ 三科卡片各带战绩（累计/正确率/错题/连对/历次模考）
  - **元气段位**：图考答对 +1 元气，连对 5/10/15… 奖励 +2；连对中断断屡不伤元气；九阶「蕴元初萌→国医气度」逐阶命名
  - **弱项优先抽样**：图考出题基于图谱账本加权（1 + 4×净错 + 0.5×错次），错>对者优先复训，题上打「弱项复训」标
  - **共享元气池**：医案每对 +1 · 模考交卷按答出率灌 2/4/6——三科段位同库，晋升一次性授予全站
  - **金榜题名仪式**：任科段位晋升弹灯笺榜（金面朱框、旧衔→新衔、元气数），3.2s 自敛或点屏即谢
  - **模考错题回流**：交卷后扫描错题题干，命中图谱术语（term 别名/引擎标签/脉名互逆）即计入 `mockMissTerms`，图考加权 +2×命中并标「模考回流」紫章，账本行同步显「模 N」
  - **回流冲销**：图考考对一次该术语即减一次模考回流权重，冲干净自动摘除紫章——无永久「夕阳题」
  - **段位全站广播**：玩界「我的」页金段卡（段位名/元气/连对纪录/距下一阶/今日日结）+ 一键入闱跳考举
  - **温故日历**：三科错题按 **1 / 3 / 7 天阶梯**自动复温列入考举首卡——医案错题直开错题回看、图考弱点即组、题库单亲「待巩固」，`到日` 红色高亮
  - **温故入提醒**：到日题目并入每日本地通知文案（App 系统级定时推「温故 N 题到日」，H5 会话 toast）
  - **出片分享**：长按图谱条目的原文卡可「出片」——SVG 组片（标题+图+释义+出处）→ 2x PNG；App 直存相册、H5 自动下载、失败降级大图长按保存
  - **本周奏报**：统计页 7 日热条 + 周绩汇总 + **拟签**（实绩定制签语：主研方向/段位进路/温故欠账），一键誊抄 4 行奏报到剪贴板
  - 可一键跳转全库检索证名原文论述；历史记录保留最近 30 次练习
  - **仅供学习辨证思路参考，不能替代执业医师面诊**
- **原文查词**：阅读器底部「查词」模式下点按段落，自动匹配方剂/中药/穴位/口诀词条，
  弹层展示卡片释义，可直达背卡或教材原文
- **全局夜间模式**：「我的 → 设置」一键转暗（书架/学习/辨证/查询/背卡/刷题全覆盖，本地记忆）
- **长辈模式**：设置页一键放大字号、加宽行距，阅读器与主要界面同步变大
- **学习提醒**：App 端本地定时系统通知（不联网不耗电），H5 端降级为每日首次打开提醒
- **数据安全**：导出/导入备份 JSON（App 存文档目录、H5 下载/选择文件），覆盖阅读进度与学习记录
- **搜索**：全库 / 单书全文检索，关键字高亮，结果直达原文位置
- **我的**：在读统计、阅读历史（带进度条）、书签管理、清空/删除
- **分享**：微信内可分享当前书籍

## 用 HBuilderX 运行

1. 安装 HBuilderX 3.6+（建议最新版），打开 “文件 → 打开目录”，选择本目录（`gmzy-app`）。
2. 首次打开时，点击 `manifest.json`，在 **基础配置** 中点 “重新获取” 自动生成 AppID。
3. 运行：
   - **运行 → 运行到内置浏览器**：即开即见的 H5 预览。
   - **运行 → 运行到手机或模拟器 → Android/iOS**：真机调试（基座）。
4. 打包安装包：
   - `manifest.json` → 基础配置：AppID 点「重新获取」，确认应用名与版本号
   - `manifest.json` → **App 图标配置**：选择已备好的 `static/icon.png`（1024×1024）
   - `manifest.json` → **App 启动图配置**：自定义启动图选择 `static/splash.png`（1125×2436）
   - **发行 → 原生App-云打包**，选 Android（apk）/iOS（ipa）即可

## 附：用 Vue CLI 构建（已通过真实构建验证）

本目录为 HBuilderX 目录结构，可直接用 HBuilderX 打开。若偏好命令行：

```bash
npm create uni@latest my-app          # 选择 Vue3 模板
cd my-app && npm install
rm -rf src && cp -r <本目录> src      # 用本目录内容替换脚手架 src
npx unh build h5                      # H5（已验证通过）
npx unh build app                     # App 打包资源（已验证通过）
# 输出在 dist/build/<platform>，App 资源可导入 HBuilderX 云打包
# H5 离线化（可选）：构建完成后执行，注入 Service Worker + Web App Manifest，
# 预缓存应用壳与全部 JSON 数据，图片首次浏览后离线可用；浏览器"添加到主屏幕"即成离线 App：
python3 tools/build_pwa.py <dist/build/h5 目录>
```

验证环境：vite 5.2.8 + @dcloudio 3.0.0-5000720260410001 + vue 3.4.21。
