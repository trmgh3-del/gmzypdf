# 光明中医文库·学习诊断系统（UniApp Vue3）

基于 **HBuilderX + UniApp（Vue3 语法）** 开发的跨平台离线中医学习 App，
收录光明中医函授教材 **26 部**全文精排内容（约 1300 万字、900+ 插图），
在完整文库之上内置**记忆卡、复习思考题、中医辨证辅助**三大学习系统，
全部数据打包在应用内，完全离线可用。

## 功能

- **书架**：封面网格、分类筛选（入门 / 经典方药 / 临床 / 针灸）、书籍简介卡
- **阅读器**：
  - 三种主题：宣纸 / 护眼绿 / 夜读；宋体 / 黑体切换；字号、行距调节
  - 目录抽屉（完整章节树，定位跳转）、进度条章节滑杆
  - 段内加粗标注、宽表格横向滚动、图片点击放大
  - 自动保存阅读进度，书签随记随取，点击空白处唤出/隐藏工具栏
  - **划线批注**：长按段落 → 三色高亮 / 写批注；「我的」页聚合成笔记清单，可回跳原文、一键导出
- **学习（tab）**：
  - **记忆卡 1795 张**：方剂卡（106 方）、中药卡（212 味）、穴位卡（394 穴）、
    口诀卡（398 诀）、医案卡（212 案）、病证卡（473 病证），全部由教材自动提取；
    翻面释读，左右滑动切换
  - **反向卡**：药/方/穴/病证四包支持「反向」模式——看功效主治回想名称，记忆提取训练
  - **综合模考**：17 卷题库随机抽 30 题、倒计时 25 分钟交卷判分；成绩曲线在「详表」展示，
    错题列单、可回教材原文，作答并入日常进度
  - **朗读（H5）**：单卡朗读、口诀卡 20 张连读（自动翻页），Web Speech 离线合成
  - **SM-2 间隔重复**：「已掌握 / 模糊 / 不认识」按记忆曲线排期（30 分钟 / 次日 / 逐次拉长），
    学习中心展示「今日待复习」到期队列，支持乱序与待巩固筛选
  - **复习思考题 1974 题**：来自 17 本教材各章后的思考题，真实章名分组，
    自问自答标记，「还没记住」自动进入待巩固队列，可按书重置进度
  - **原文联动**：每张卡片、每道题都带教材锚点，一键跳转阅读器对应原文段落
  - 学习总览：连续学习天数 streak、今日已学/待复习、近 7 日学习量柱状图
- **辨证（tab）**：依据教材证型规律编写的辅助推理系统
  - 按 11 组 88 项勾选症状、舌脉与妇科/出血表现 → 在 39 个常见证型中给出加权吻合度排序（Top 4）
  - 覆盖六经八纲、卫气营血（卫/营/血分）、脏腑、气血津液、妇科（痛经/带下）、儿科（食积）
  - 每个证型附：命中症状、病机、治法、代表方（含出处）、参考穴位、教材出处
  - **相近证型鉴别**：前两名分差 <15% 时，自动展示教材鉴别要点（如风寒/表虚辨汗）
  - 可一键跳转全库检索证名原文论述；历史记录保留最近 30 次练习
  - **仅供学习辨证思路参考，不能替代执业医师面诊**
- **原文查词**：阅读器底部「查词」模式下点按段落，自动匹配方剂/中药/穴位/口诀词条，
  弹层展示卡片释义，可直达背卡或教材原文
- **全局夜间模式**：「我的 → 设置」一键转暗（书架/学习/辨证/查询/背卡/刷题全覆盖，本地记忆）
- **长辈模式**：设置页一键放大字号、加宽行距，阅读器与主要界面同步变大
- **学习提醒**：App 端本地定时系统通知（不联网不耗电），H5 端降级为每日首次打开提醒
- **数据安全**：导出/导入备份 JSON（App 存文档目录、H5 下载/选择文件），覆盖阅读进度与学习记录
- **搜索**：全库 / 单书全文检索，关键字高亮，结果直达原文位置
- **我的**：在读统计、阅读历史（带进度条）、书签管理、清空/删除
- **分享**：微信内可分享当前书籍

## 用 HBuilderX 运行

1. 安装 HBuilderX 3.6+（建议最新版），打开 “文件 → 打开目录”，选择本目录（`gmzy-app`）。
2. 首次打开时，点击 `manifest.json`，在 **基础配置** 中点 “重新获取” 自动生成 AppID。
3. 运行：
   - **运行 → 运行到内置浏览器**：即开即见的 H5 预览。
   - **运行 → 运行到手机或模拟器 → Android/iOS**：真机调试（基座）。
4. 打包安装包：
   - `manifest.json` → 基础配置：AppID 点「重新获取」，确认应用名与版本号
   - `manifest.json` → **App 图标配置**：选择已备好的 `static/icon.png`（1024×1024）
   - `manifest.json` → **App 启动图配置**：自定义启动图选择 `static/splash.png`（1125×2436）
   - **发行 → 原生App-云打包**，选 Android（apk）/iOS（ipa）即可

```
├── components/          # BookCover / BlocksView / ChapterDrawer / SettingsPanel / DictSheet
└── pages/
    ├── index/           # 书架（tab）
    ├── learn/           # 学习中心（tab）

```

## 附：用 Vue CLI 构建（已通过真实构建验证）

本目录为 HBuilderX 目录结构，可直接用 HBuilderX 打开。若偏好命令行：

```bash
npm create uni@latest my-app          # 选择 Vue3 模板
cd my-app && npm install
rm -rf src && cp -r <本目录> src      # 用本目录内容替换脚手架 src
npx unh build h5                      # H5（已验证通过）
npx unh build app                     # App 打包资源（已验证通过）
# 输出在 dist/build/<platform>，App 资源可导入 HBuilderX 云打包
# H5 离线化（可选）：构建完成后执行，注入 Service Worker + Web App Manifest，
# 预缓存应用壳与全部 JSON 数据，图片首次浏览后离线可用；浏览器"添加到主屏幕"即成离线 App：
python3 tools/build_pwa.py <dist/build/h5 目录>
```

验证环境：vite 5.2.8 + @dcloudio 3.0.0-5000720260410001 + vue 3.4.21。
